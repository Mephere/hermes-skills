# Formules a supprimer

Liste de controle appliquee a l'etape 7 du deroulement. Chaque tournure trouvee est
retiree ou remplacee, et la substitution est reportee dans le bloc de controle.

## Excuses non justifiees

| A supprimer | Remplacement |
|---|---|
| Je me permets de vous ecrire | <supprimer, commencer par le message> |
| Desole de vous deranger | <supprimer> |
| Excusez-moi de revenir vers vous | Je reviens vers vous au sujet de... |
| J'espere ne pas abuser de votre temps | <supprimer> |

## Precautions qui affaiblissent la demande

| A supprimer | Remplacement |
|---|---|
| Je ne sais pas si c'est possible mais | <formuler la demande directement> |
| Serait-il eventuellement envisageable de | Pouvez-vous... |
| Si jamais vous avez un moment | <remplacer par une date> |
| Quand vous aurez le temps | Avant <jour, heure> |
| Je pense que peut-etre | <affirmer ou retirer> |

## Formules de fin creuses

| A supprimer | Remplacement |
|---|---|
| N'hesitez pas a revenir vers moi | <supprimer, ou poser une question precise> |
| Au plaisir de vous lire | <supprimer> |
| Dans l'attente de votre retour | <supprimer si une echeance figure deja> |
| En vous remerciant par avance de votre comprehension | Merci. |

## Ouvertures qui retardent le message

| A supprimer | Remplacement |
|---|---|
| J'espere que vous allez bien | <supprimer sauf relation reellement personnelle> |
| Comme evoque lors de notre derniere reunion | <deplacer apres le message principal> |
| Pour faire suite a nos echanges | <deplacer apres le message principal> |

## Regles generales

- Supprimer les adverbes de precaution : simplement, juste, rapidement, eventuellement.
- Supprimer le conditionnel quand l'indicatif suffit : « je voudrais » devient « je demande ».
- Un seul remerciement par email, a la fin.
- Aucun point d'exclamation dans un registre formel.
